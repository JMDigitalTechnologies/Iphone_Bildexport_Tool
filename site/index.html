iPhone-Fotos sortiert auf den PC holen

Per USB-Kabel, sortiert nach deinen Alben, nach Personen oder nach Jahr und Monat. Als Originaldateien, ohne Cloud und ohne Konto.

Kostenlos herunterladen Live-Demo öffnen

Der normale Windows-Import kennt nur den Ordner DCIM. Dieses Tool liest die Sortierung aus der Fotos-App.

iPhone Foto-Export

Probier es aus: Das ist die echte Oberfläche, hier mit Beispieldaten statt eines iPhones.

Was das Tool kann

Wähle aus, was du brauchst, und kombiniere es beliebig in einem Durchgang.

Nach Alben

Jedes Album der Fotos-App wird ein eigener Ordner, mit allen Fotos und Videos darin.

Nach Personen

Nutzt die Gesichtserkennung des iPhones: ein Ordner pro benannter Person.

Nach Jahr & Monat

Die ganze Mediathek nach Aufnahmedatum, mit einem Klick auf „Ganzes Jahr“.

Fotos, Videos & Live Photos

Originaldateien (HEIC, JPG, MOV), Videos wahlweise mit oder ohne, dazu Live-Photo-Clips und bearbeitete Versionen.

Alles lokal

Keine Cloud, kein Konto, keine Datenübertragung ins Internet. Auf dem iPhone wird nichts verändert.

Fortsetzen

Bereits kopierte Dateien werden übersprungen. Ein abgebrochener Export läuft einfach weiter.

Ordentliche Ordner statt Dateichaos

So landen die Fotos im Zielordner deiner Wahl:

  • Ein Foto in mehreren Alben wird in jeden passenden Ordner kopiert.
  • Das Dateidatum entspricht dem Aufnahmedatum.
  • Fotos, die nur in iCloud liegen, holt das Tool über iCloud für Windows nach.

Installation unter Windows

Einmalig in etwa fünf Minuten eingerichtet.

  1. Python installieren

    Python 3.10 oder neuer von python.org installieren. Beim Installieren den Haken bei „Add python.exe to PATH“ setzen.

    python.org öffnen

  2. Apple-Gerätetreiber

    Die App „Apple Geräte“ (Apple Devices) aus dem Microsoft Store oder iTunes installieren. Sie bringt den USB-Treiber für das iPhone mit.

  3. Optional: iCloud für Windows

    Nutzt dein iPhone „iPhone-Speicher optimieren“, liegen die Originale nur in iCloud. Installiere dann iCloud für Windows aus dem Microsoft Store, melde dich an und aktiviere „Fotos“. Das Tool holt fehlende Originale automatisch von dort.

  4. Tool herunterladen und entpacken

    ZIP herunterladen und in einen Ordner deiner Wahl entpacken, zum Beispiel unter Dokumente.

    ZIP herunterladen

  5. Starten

    Doppelklick auf iPhone Fotos starten.bat. Beim ersten Start wird die benötigte Bibliothek automatisch installiert, danach öffnet sich die Oberfläche im Browser. iPhone anschließen, entsperren, „Diesem Computer vertrauen“ tippen und loslegen.

Häufige Fragen

Mein iPhone nutzt „iPhone-Speicher optimieren“. Geht das trotzdem?

Ja, mit iCloud für Windows. Dann liegen die Originale nur in iCloud und lassen sich per USB nicht laden. Ist auf dem PC iCloud für Windows mit „Fotos“ eingerichtet, holt das Tool fehlende Originale automatisch von dort; die Sortierung nach Alben, Personen und Datum kommt weiter vom iPhone. Fehlt die Anmeldung bei iCloud, pausiert der Export mit einem Hinweis und läuft danach von selbst weiter. Ohne iCloud für Windows: auf dem iPhone unter Einstellungen → Fotos „Laden und Originale behalten“ wählen.

Warum fehlen Personen in der Liste?

Es erscheinen nur Personen, denen du in der Fotos-App einen Namen gegeben hast (Alben → Personen). Danach in der Oberfläche auf „Neu laden“ klicken.

Werden meine Fotos irgendwohin hochgeladen?

Nein. Das Tool läuft komplett auf deinem PC. Die Oberfläche ist eine lokale Seite (127.0.0.1), die nur von deinem Rechner aus erreichbar ist. Auf dem iPhone wird nichts verändert oder gelöscht.

Funktioniert das mit jedem iPhone?

Entwickelt für aktuelle iPhones (zum Beispiel iPhone 14) mit aktuellem iOS. Das iPhone muss per USB verbunden, entsperrt und dem PC vertraut sein. Läuft etwas nicht, gerne ein Issue auf GitHub anlegen.

Was kostet das Tool?

Nichts. Es ist Open Source unter der MIT-Lizenz und darf frei genutzt, verändert und weitergegeben werden.

Läuft das auch auf dem Mac?

Die Oberfläche und der Start sind für Windows gebaut. Auf dem Mac gibt es mit der Fotos-App bereits einen eingebauten Export.
